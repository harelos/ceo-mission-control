Agent Company Plan

The original conclusion: a bigger agent org chart is not the objective. Build a smaller organization of responsibilities, durable work orders, strict quality gates and measured autonomy.

3 departments5 role profiles2 concurrent jobs max in pilot1 repair + 1 consultation
Available 24/7 should mean the system can respond and continue eligible work—not that expensive models are permanently thinking.

What the research changed

Hierarchy is not enough

Agent managers can create bureaucracy and spend. The useful unit is a bounded work order with evidence and a stop condition.

Procedure beats conversation

Use deterministic queues, quotas, retries, state and acceptance checks wherever judgment is not needed.

Quality needs a contract

Define “correct + verified + commercially usable” before execution. One repair, then pass or block.

What other agent systems spent

~$800

RepoMirror experiment

Self-reported six repository ports overnight, slightly under $800 in inference. Some outputs still needed repair and agents sometimes continued longer than useful.

~$20k

Anthropic compiler experiment

16 agents, roughly two weeks and nearly 2,000 sessions. Demonstrates capability and the very real cost of large-scale parallel autonomy.

Not the point

Project Vend

AI shopkeeper/CEO experiments showed that an extra manager can create long conversations without proportional business value. Better procedures and tools mattered.

Figures above are experiment reports, not a forecast for Foundry or a claim about subscription economics.

How work moves while the CEO is gone

QUEUED→RUNNING→VERIFYING→COMPLETEREPAIRBLOCKED

A persistent backlog determines the next eligible work item. The manager wakes for planning, completion review, exceptions and daily close—not every few minutes.

Pilot rule: at most two concurrent jobs globally, one initial attempt, one repair, one consultation and one model escalation per root work order. Child jobs cannot reset the budget.

Foundry-specific checks before trusting unattended work

Usage telemetry

The inspected Foundry main-branch Codex completion path appeared to store zero token/cost values locally. Verify actual runtime telemetry before believing the ledger.

Restart recovery

The inspected load path disables autonomous loops after restart. Preserve the safety behavior and recover authorized work through durable task state.

Subscription ≠ API wallet

Measure real plan quota/rate-limit behavior. Never silently fall back to paid API spend just to keep an agent working.

Day-one vertical slice

  1. Audit the actual running Foundry version and authentication mode.
  2. Verify real quota/token telemetry and restart behavior.
  3. Create one durable work order with frozen acceptance criteria.
  4. Run one useful local Growth job after the CEO closes the browser.
  5. Deliberately restart the service and verify safe recovery.
  6. Run 72 hours before expanding the org chart or authority.

The seven-day north star

The CEO leaves. The company continues to produce SEO/product work, create and QA ad concepts, handle eligible operational exceptions, and accumulate evidence. On return the CEO gets a short list of true decisions—not a week of agents waiting.

“The business moved forward, quality was checked, resource use was recorded, and the CEO did not have to supply the next instruction.”
