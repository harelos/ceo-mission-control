# 05 — פרסום וקריאייטיב

## עקרונות פעילים
- לשמור מנצחים קיימים ללא שינוי בזמן שבודקים זוויות חדשות.
- לבדוק משפחות קריאייטיב לפי כאב/מסר, לא רק וריאציות עיצוב.
- להתאים את המסר במודעה לזווית בדף המכירה.
- לתת יותר נוכחות לשחור ולחום כהה, ולבדוק בצורה מבוקרת את חום בהיר וגוונים נוספים.

## משפחות זווית לבדיקה
- עלות המספרה / עלות שורשים חוזרת
- חבילת 4 והערך שלה
- ביטחון בגוון
- שיער לבן ושורשים עקשניים
