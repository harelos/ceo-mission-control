# 03 — קופי ומסרים

מקום לזוויות, כותרות, ניסוחים, שפה ישראלית, התנגדויות ומסרים שנבדקו.

## כללים פעילים
- עברית טבעית, לא תרגום מאנגלית.
- מסרים ישירים וספציפיים.
- להפריד בין זווית שנבדקה לבין רעיון חדש.
- להתאים את המסר לדף שאליו המודעה שולחת.

## זוויות פעילות למחקר
- עלות השורשים החוזרת
- ביטחון בגוון
- כיסוי שיער לבן ושורשים עקשניים
- שגרת צביעה ביתית פשוטה
