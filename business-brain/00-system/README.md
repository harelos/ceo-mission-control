# 00 — מפת המוח והוראות שימוש

## תפקיד התיקייה

המקום שמגדיר איך קוראים, כותבים ומעדכנים את מוח העסק.

## סדר עדיפויות בין מקורות

1. אמת עסקית נוכחית
2. החלטה אסטרטגית מתועדת
3. ניסוי ותוצאה
4. נתון ממערכת/ספק/מסמך מקור
5. מחקר לקוחות
6. מקור חיצוני
7. השערה או רעיון
8. ארכיון

## כלל מקור אמת

אם יש סתירה בין מסמך ישן לבין `01-current-truth`, מקור האמת הנוכחי גובר עד שיוכח אחרת.

## כתיבה לסוכנים

כל מסמך צריך להיות:
- קצר וברור בראשו
- עם תאריך עדכון
- עם מצב: פעיל / לבדיקה / ארכיון
- עם עובדות בנפרד מהשערות
- עם קישורים לראיות כאשר קיימים
